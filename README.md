# TerraKlink

Корпоративный сайт производителя кирпича для Казахстана: русский и казахский
языки, каталог, формы заявок, редактор контента, аналитика и управление.
Композиция и оформление основаны на [референсе клиента](https://likolorpro.ru).
Контакты, товары и материалы сейчас демонстрационные.

## Запуск за несколько команд

Нужны Git, uv и работающий Docker с Compose v2. Из корня проекта:

```powershell
uv run --frozen scripts/prepare_env.py
docker compose config --quiet
docker compose up --build -d --wait
docker compose exec backend python manage.py createsuperuser
```

Последняя команда нужна, если администратора ещё нет. Скрипт подготовки сохраняет
существующий `.env`; секреты создаёт локально и не печатает. При обновлении данные
в именованных томах сохраняются. **Не используйте `docker compose down -v`.**

| Приложение | Адрес |
|---|---|
| Сайт | http://localhost:80 |
| Редактор секций, баннеров и товаров | http://localhost:80/admin |
| Аналитика | http://localhost:80/analytics |
| Заявки, история, медиатека | http://localhost:80/management |
| Пользователи и системные записи | http://localhost:80/django-admin/ |
| MinIO Console, только локально | http://localhost:9001 |

Вход в приложения — созданный staff-пользователь Django. MinIO использует отдельные
значения `MINIO_ROOT_USER`/`MINIO_ROOT_PASSWORD` из локального `.env`.
Случайный пароль локального dev-редактора, если создан через `setup_dev.py`,
находится в `.local/admin-password.txt`. Реальные пароли в репозиторий не входят.

## Что можно редактировать

- Текст, шрифты, цвета, фото и видео секций; порядок — номером, перетаскиванием
  либо стрелками. Сохранение создаёт черновик, публикация меняет сайт.
- Шаблон баннера и анимацию; русскую и казахскую версии контента.
- Товары, характеристики, галерею до 12 фото и промо с картинкой/ценой/датами.
  Стрелки карусели появляются при двух и более фото.
- SEO/GEO, контакты и лимиты загрузки; см. подробные инструкции ниже.

## Стек и правила

Frontend: TypeScript, React, Redux Toolkit/RTK Query. Backend: Django, DRF, JWT,
Gunicorn. Данные: PostgreSQL и MinIO. Nginx, Docker Compose, GitHub Actions;
production дополнительно использует Caddy и Redis.

Python-зависимости — **uv**, `pyproject.toml` + `uv.lock`; frontend — **npm**,
`package.json` + `package-lock.json`. Рабочая ветка — `dev`. В `main` попадают
проверенные релизы через pull request после успешных `api` и `web`.
Полные правила — [AGENTS.md](AGENTS.md).

Публичный VPS и домен клиента отдельно от локального запуска. Демонстрационные
материалы референса и юридические тексты требуют согласования перед публикацией.
