# Казахстан: требования и границы проверки

Сайт предназначен для частной компании в Казахстане. Формулировка «все ГОСТы» не определяет проверяемый перечень. Проект не заявляет сертификацию или полное соответствие стандарту по результату одного автоматического теста.

## Персональные данные

Источник: [Закон РК «О персональных данных и их защите»](https://old.adilet.zan.kz/rus/docs/Z1300000094), в частности правила согласия, хранения, защиты и трансграничной передачи. [Правила сбора, обработки персональных данных](https://old.adilet.zan.kz/rus/docs/V2000021498) дополняют порядок работы оператора.

Реализовано: отдельное непредустановленное согласие в форме, серверное отклонение заявок без согласия, сохранение времени и версии согласия, ограниченный доступ сотрудников к заявкам, выбор cookies с возможностью отказа от необязательных, отдельное разрешение на геолокацию, отказ от внешнего определения города по IP. Аналитические сервисы отсутствуют.

Перед рабочим запуском определить юридического оператора и реквизиты, действующий контакт для обращений, конкретный срок хранения, процедуру исправления/отзыва/удаления и роли сотрудников; утвердить документы. Автоматическая очистка по сроку хранения пока не настроена, поскольку срок не согласован. PostgreSQL, резервные копии и хранилища с персональными данными нужно размещать в Казахстане. Compose определяет компоненты, но не гарантирует географию их размещения.

Точный перечень действий, получателей и сроков должен соответствовать реальным процессам клиента. Рабочие юридические документы нельзя считать утверждёнными только по демонстрационному шаблону.

## Доступность

[ГОСТ Р 52872-2019](https://protect.gost.ru/gost/details/2d10ff38-d609-4dcc-899f-c18b77ac0b75) — российский стандарт доступности; применимость к частному сайту Казахстана не предполагается автоматически. Казахстанские требования к государственным интернет-ресурсам также нельзя без анализа объявлять обязательными для частной компании.

Включены семантическая разметка, подписи форм, управление с клавиатуры, видимый focus, пропуск к содержимому, native modal dialog с удержанием фокуса, текстовые сообщения ошибок и reduced-motion. Проверяется отсутствие горизонтального переполнения на desktop/mobile.

Полная проверка контраста всех пользовательских цветов, экранными дикторами, доступности баннеров с текстом внутри изображений и субтитров видео не завершена. Редактор может выбрать недостаточно контрастный цвет; ограничение палитры и автоматический валидатор контраста потребуют согласования. Рекламный баннер референса — растровый текст, поэтому для рабочего запуска нужен доступный текстовый эквивалент всех значимых условий. Видео должны сопровождаться соответствующими субтитрами/транскриптом.
